# ContactHub 项目计划

## 起点

检查时 `ExtremeProgramming1` 是空目录，Git 状态、远程、分支和日志命令均返回无仓库。目录内没有 README、构建、应用、测试、部署配置、仓库指令或待保留的修改。课程公开帖列出 Fork，但未列上游地址。学生在任务中确认允许自建，因此使用新仓库；课程上游 Fork 不适用这条自建路径。

## 方案和顺序

1. 使用 Vite、原生 JavaScript、HTML 和 CSS 初始化可构建项目。建立联系人模型、存储和增删改查界面。
2. 增加收藏筛选和可重复的四类联系方式输入。数据层以 UUID 联系人 ID 为键，收藏与联系方式分别更新。
3. 用 ExcelJS 编解码真实 XLSX。表头按类型扩展，导入先解析与验证，再预览并追加。共享联系人校验。
4. 用 Vitest 验证模型与 XLSX 往返，用 Playwright 检查真实浏览器事件、持久化和窄屏。证据来自实际运行。
5. 整理规范、测试、演示和博客材料。自建仓库使用 `main` 作为基线与 PR 目标，真实功能提交在 `feature/extreme-programming-address-book`。通过验收后发布 `v1.0.0`。基础交付完成后评估云部署。

## 模块

- 联系人模型处理规范化、校验、搜索与重复匹配。
- 存储模块拥有状态，调用模型，成功保存后才提交内存变更。
- Excel 模块依赖模型与 ExcelJS，负责工作簿、表头和逐行错误。
- 主入口连接用户事件、存储和 Excel。UI 模块只负责生成节点及表单。
- 独立的测试覆盖模型、导入导出和浏览器界面。

## 验收

- 可新增、查看、编辑、删除和搜索。允许同名联系人，刷新后数据保留。
- 收藏可切换并筛选。编辑、刷新和 Excel 往返保留收藏状态。
- 电话、邮箱、社交账号和地址都可重复添加、编辑和删除。
- XLSX 一人一行，编号列动态扩展，前导零和国际号码保留。可追加正确记录并显示导入计数；损坏文件保留原数据。
- 桌面及窄屏操作可用。干净依赖安装、自动测试和生产构建有实测结果。
- 至少三次真实开发提交。仓库、PR、Release 与部署以实际状态记录。博客包含作业说明、目录、截图、视频位置和每人 PSP。
