# 功能与验收入口

| 作业评分 | 应用入口 | 可观察结果 |
| --- | --- | --- |
| 收藏 25 分 | 点击联系人星星并进入 Favorites | 实心星、收藏计数、筛选、取消与刷新恢复 |
| 多联系方式 10 分 | Add Contact 或 Edit，点击 Add Phone、Add Email、Add Social、Add Address | 可增加任意多条同类项，逐条移除，View 展示全部 |
| Excel 25 分 | Export Excel、Import Excel、Download Template | 一人一行、动态编号文本列、预览/提交、重复与错误计数 |
| 样式 10 分 | 首页、空状态、对话框、窄屏 | 联系人卡片与清晰导航，可聚焦操作控件 |
| 作业文档 30 分 | README、编码规范、博客与证据 | 真实截图、视频、GitHub 记录及个人 PSP 模板 |

基础管理支持查看详情、增删改、姓名/电话/邮箱搜索与重启后的浏览器存储恢复。示例联系人来自录屏自动化输入的测试数据。
