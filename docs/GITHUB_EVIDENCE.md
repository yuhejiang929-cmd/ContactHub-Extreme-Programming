## 统计口径

合并前用 `git shortlog -sn main..feature/extreme-programming-address-book` 查看功能分支相对基线的作者计数。合并后按最终发布快照和主 PR 的提交列表统计。用 `git shortlog -sn --no-merges v1.0.0` 可查看版本中的非合并提交，包含自建基线。Codex 开发提交使用独立署名，学生实际参与由本人据实补充。
