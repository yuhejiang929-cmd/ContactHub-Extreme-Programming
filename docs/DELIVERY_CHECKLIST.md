# 交付清单

- [ ] 本人复跑核心功能，按课程要求理解并复核实现。
- [ ] 检查 GitHub 仓库、编码规范、PR 和 Release 链接，核对证据中的统计范围。
- [ ] 在博客填写个人或组队信息。组队时补真实分工、合计 100% 的贡献比例及协作记录。
- [ ] 填写自己的预计与实际 PSP 时间，核对各列合计。
- [ ] 上传程序截图、真实 GitHub 提交截图与完整视频，检查它们可公开访问。
- [ ] 核对云部署加分口径，按实际部署状态描述。
- [ ] 在 CSDN 发布与检查审查状态，以无痕窗口打开最终博客。
- [ ] 在课程作业帖提交自己的最终博客链接，并确认显示已提交。

自动执行的项目状态见 [交付报告](../DELIVERY_REPORT.md)。个人博客发布与课程提交按 [发布指南](BLOG_PUBLISHING_GUIDE.md) 完成。
