# CSDN 博客发布与课程提交

1. 打开 [博客初稿](CSDN_BLOG_DRAFT.md)，选择个人或组队描述，填写本人的 PSP 时间和真实参与内容。组队时填写两人真实分工、贡献比例和合作问题，比例合计 100%。
2. 在 CSDN 创作中心新建 Markdown 文章，把初稿复制进去。将作业说明表保留在目录之前。正文的相对链接需要换成可访问的 GitHub URL 或编辑器上传后返回的媒体链接。
3. 上传 [程序截图](screenshots/) 和实拍的 GitHub 提交截图。图片上传成功后，把编辑器生成的地址替换 Markdown 图片地址。预览中确认图像、表头、目录锚点和中文显示。
4. 上传 [完整运行视频](demo/contacthub-demo.mp4)。如果当前博客编辑器不提供视频上传，可以附上公开视频或 GitHub Release 视频资产链接。现有资产已通过匿名下载核对。 [公开的 Release MP4](https://github.com/yuhejiang929-cmd/ContactHub-Extreme-Programming/releases/download/v1.0.0/contacthub-demo.mp4)
5. 核对项目、编码规范、PR、Release 和演示链接。发布文章并查看审核状态，等公开正文可见后复制最终文章地址。
6. 登录课程社区，打开作业原帖的「提交任务」。选择或粘贴本人博客，按页面要求提交并确认自己的提交记录。正式截止为北京时间 2026-11-17 23:59，尽早发文以留出审核时间。组队的每位学生均应登录自己的账号提交。 [CSDN 作业入口](https://bbs.csdn.net/topics/620593436)
